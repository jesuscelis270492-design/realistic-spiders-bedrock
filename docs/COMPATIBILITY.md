## Conflictos Conocidos y Soluciones

### Problema: Telarañas desaparecen
**Causa**: Addon de limpieza automática
**Solución**: Desactiva limpieza automática en config

### Problema: Arañas spawning en exceso
**Causa**: Amplificador de spawning de criaturas
**Solución**: Reduce spawn rate del addon amplificador

### Problema: Texturas incorrectas
**Causa**: Conflicto de resource packs
**Solución**: Reordena packs, Realistic Spiders RP al inicio

### Problema: Criaturas lentas
**Causa**: Muchos addons de criaturas a la vez
**Solución**: Mantén máximo 2-3 addons de criaturas

## Configuración Recomendada

### Para Máximo Rendimiento
```
1. Realistic Spiders BP (behavior pack)
2. Realistic Spiders RP (resource pack)
3. Ningún otro addon de criaturas
4. 1-2 addons decorativos OK

Configuración de Mundo:
- Dificultad: Normal o Difícil
- Spawn límite: 90-110 (por defecto)
- Distancia: 128 bloques
```

### Para Compatibilidad Máxima
```
Compat Tier 1 (Definidas compatibles):
1. Realistic Spiders BP
2. Realistic Spiders RP
3. Better Animals Plus
4. Furniture Addon
5. Vanilla Tweaks

Orden importante:
- Realistic Spiders debe estar 2-3 posición
- Otros addos después
```

### Para Uso Casual
```
1. Realistic Spiders BP
2. Realistic Spiders RP
3. 2-4 addons decorativos/contenido
4. Maximum 1 addon de física
```

### Windows PC
- **OS**: Windows 10 22H2 o Windows 11
- **RAM**: 4GB mínimo (8GB recomendado)

## Testeo de Compatibilidad

### Cómo reportar incompatibilidades

1. Documenta claramente:
   - Addon conflictivo exacto
   - Versión de ambos addons
   - Pasos para reproducir
   - Mensajes de error

2. Abre issue en GitHub con:
   ```
   Título: [INCOMPATIBILITY] Addon X vs Realistic Spiders
   
   Addons instalados:
   - Realistic Spiders v1.0
   - [Otro addon] v1.2
   
   Problema: [Describir]
   Pasos: [Listar]
   ```

3. Comunidad evaluará compatibilidad
